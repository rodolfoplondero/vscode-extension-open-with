# Open With External Application v0.2.0

This version uses English names throughout the current extension interface, documentation, and technical identifiers.

- Author: **Rodolfo Londero**
- Extension ID: `rodolfoplondero.open-with-external`
- Open command: `openWithExternal.open`
- Settings filter: `@ext:rodolfoplondero.open-with-external`

## Install or migrate

This is a new extension identity and requires a new installation. If you have version 0.1.x, find it in Extensions using `@id:local-tools.abrir-com-externo`, uninstall it, and reload the window. Then use **Install from VSIX…** to install `open-with-external-0.2.0.vsix`.

Existing `openWithExternal.*` settings remain valid. Update custom keybindings and integrations to use `openWithExternal.open`. Enable only the new extension to avoid duplicate commands and settings conflicts.

## Settings

In Settings, search for `@ext:rodolfoplondero.open-with-external` to configure **Cache Duration Minutes**, **Preload Enabled**, and **Preload Extensions**.

Application discovery, caching, and background preloading retain their existing behavior. Application names and the native Windows dialog follow the operating system language.
