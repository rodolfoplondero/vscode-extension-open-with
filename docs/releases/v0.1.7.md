# Open With External Application v0.1.7

Open local files with Windows applications from a searchable picker in VS Code or a compatible editor. Requires Windows and VS Code API version 1.96 or later. VSCodium compatibility is expected but has not been separately tested.

## What's included

- Reuse application lists by file extension for a configurable interval: 5 minutes by default; 0 disables caching.
- Preload applications in the background for common formats found in local workspace folders. Enable or disable preloading and edit the format list in the extension settings.
- Respect workspace exclusions and limit each preload pass to 5,000 matching paths across local folders. Explicit Open With requests take priority over background queries.
- Keep the Windows application chooser available during search, allow cancellation of discovery, explain busy operations, and offer recovery after a launch failure.
- Show simpler picker rows and clearer messages when no recognized DOCX editor is found.

## Installation

1. Download `open-with-external-0.1.7.vsix` from this release's assets.
2. In the editor, open Extensions, select the **…** menu, and choose **Install from VSIX…**.
3. Select the downloaded package and reload the window if prompted.
4. In Settings, search for `@ext:local-tools.abrir-com-externo` to configure Cache Duration Minutes, Preload Enabled, and Preload Extensions.
